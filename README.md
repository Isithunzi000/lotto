# Kalkulator Lotto EV/RTP

Kalkulator wartości oczekiwanej (EV/RTP) gier liczbowych Totalizatora Sportowego:
Lotto, Multi Multi, Eurojackpot, Mini Lotto, Ekstra Pensja.

## Użycie

Wersja online (GitHub Pages): **https://isithunzi000.github.io/lotto/**

Można też pobrać `index.html` i otworzyć lokalnie w przeglądarce — kalkulator
działa w pełni offline, bez serwera.

## Funkcje

- Obliczanie EV/RTP z uwzględnieniem kumulacji i promocji
- Historia losowań, statystyki, generatory kuponów i systemów
- Raporty syntetyczne i symulacje budżetu
- Zapisywanie parametrów wejścia
